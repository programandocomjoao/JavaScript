Inserindo JS no HTML - Forma 4

O JavaScript é uma linguagem de programação criada em 1995 por Brendan Eich, enquanto trabalhava na Netscape. A linguagem foi desenvolvida em um período de rápida expansão da internet, quando os sites ainda eram predominantemente estáticos. A ideia era criar uma ferramenta que permitisse adicionar interatividade às páginas da web, tornando a experiência dos usuários mais dinâmica.

Inicialmente, o JavaScript foi desenvolvido em apenas alguns dias e recebeu o nome de Mocha. Depois, passou a ser chamado de LiveScript e, posteriormente, JavaScript. Apesar da semelhança no nome, JavaScript não é uma versão do Java: são linguagens diferentes, criadas com objetivos e características próprias. O nome JavaScript surgiu principalmente por razões comerciais relacionadas à popularidade do Java na época.

Com o crescimento da web, tornou-se importante estabelecer um padrão para a linguagem. Em 1997, o JavaScript foi submetido à ECMA International, organização responsável pela criação de padrões tecnológicos, dando origem ao ECMAScript. A partir daí, novas versões da especificação foram desenvolvidas, trazendo recursos que ajudaram a tornar a linguagem mais organizada, poderosa e adequada às necessidades dos desenvolvedores.

Durante os anos 2000 e 2010, o JavaScript passou por uma grande transformação. Bibliotecas e frameworks como jQuery, Angular, React e Vue facilitaram o desenvolvimento de aplicações web cada vez mais complexas. Além disso, o surgimento do Node.js permitiu que o JavaScript fosse executado também no lado do servidor, ampliando significativamente suas possibilidades de uso para além dos navegadores.

Atualmente, o JavaScript é uma das linguagens de programação mais utilizadas no mundo. Ele está presente em sites, aplicações web, servidores, aplicativos móveis, ferramentas de desktop e diversos outros sistemas. Sua evolução ao longo das décadas demonstra como uma linguagem criada originalmente para adicionar pequenos elementos de interatividade às páginas web se tornou uma das principais tecnologias do desenvolvimento de software moderno.
